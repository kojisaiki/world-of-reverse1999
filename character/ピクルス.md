# ピクルス

- **レア度**: ★6

## 人物概要
1966年ロンドンのリメカップ窃盗事件において、茂みに隠されていた本物のトロフィーを発見・回収した哲学的な名犬（コリー犬）。

なお、同じ1966年ロンドンを舞台とするメインストーリー[[第0章「明日へ」]](../story/main/第0章_明日へ.md)（[第4節「咀嚼と優美」](https://uttu.merui.net/story/jp/main/chapter-0?part=4)）でも、街頭の新聞売りの少年が「英雄ピクルスが出演する最新映画が今週の土曜日から上映開始！ あのワンちゃんが、どうやって泥棒からワールドカップを取り戻したのか、みんな見に来てね！」と呼び込みを行っており、当時のロンドン市民の間で国民的英雄として親しまれている様子が描かれている。
