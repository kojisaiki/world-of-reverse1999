# メレル（Merel）

## 基本情報
- **本名**: メレル・ファン・デル・フェール（Merel Van der Veer）
- **本源**: 神秘学者
- **年齢**: 16歳
- **コードネーム**: クロウタドリ（Blackbird）
- **活躍年代・場所**: 聖パブロフ財団人類第一防衛線学校、1991年南極（第10章）、1920年代ヨーロッパ西部戦線・各作戦地域（第11章〜第13章）
- **所属**: 聖パブロフ財団
  - 人類第一防衛線学校（SPDM）卒業生
  - 監視局（Vigiles Bureau）研修生
  - 機動部隊「第XII部隊（"XII" Squad）」隊員
- **得意な神秘術**: 変身術（シオマネキ・カニへの変身など、物品隠蔽や姿の偽装）

## 人物概要
幼い頃に「ストーム」によって孤児となり、聖パブロフ財団に引き取られて人類第一防衛線学校（第一防衛学校 / SPDM）で育てられた16歳の神秘学者の少女。

[[ヴェルティ]](ヴェルティ.md)や[[ソネット]](ソネット.md)、[[マチルダ]](マチルダ.md)とは防衛学校の同年代・同級生（同世代）にあたる。厳しい規律と管理で縛られた学校生活を「監獄のようだ」と感じており、目立たず平穏な生活を送るために「わざと最下位の成績で卒業し、財団での就職を免れて外の世界で普通の人間として暮らす」ことを企てていた。自由時間は主に図書館で過ごし、課外図書『初心者のためのシオマネキ変身術』から独学でカニへの変身術を習得。また、ヴェルティたちが起こした集団脱走事件の噂を聞き、「伝説の生徒ランキングがあるなら彼女が1位だろう」と密かに感銘を受けていた。

しかし卒業時、その目論見とは裏腹にクレイウスに見出されて監視局の研修生に任命され、脱出計画は失敗。その後、クレイウス率いる機動部隊「第XII部隊」にコードネーム「クロウタドリ（Blackbird）」として配属されることとなった。

メインストーリー第2部終盤の[[第10章「復楽園」]](../story/main/第10章_復楽園.md)では、[[ウルリッヒ]](ウルリッヒ.md)の研究護衛として南極調査に同行し初登場。続く第3部の[[第11章「果てなき道を進みて」]](../story/main/第11章_果てなき道を進みて.md)や[[第12章「遠征譚」]](../story/main/第12章_遠征譚.md)ではヨーロッパ西部戦線の最前線へ派遣され、過酷な戦場で[[マルシャ]](マルシャ.md)や[[カローン]](カローン.md)らと交流を深めながら前線で奮闘した。大好物はチョコレートで、作中でも度々口にしている。

[[第13章「他者の哀しみ」]](../story/main/第13章_他者の哀しみ.md)において、仲間や避難民を守るため前線で奮戦するが、ストームの反転（リバース）の濁流に呑まれて犠牲となり姿を消す。ストーム通過後のイギリス・ウェールズ地方において、ヴェルティとソネットは彼女と瓜二つの姿をした少女[[リアンノン]](リアンノン.md)と出会うことになる。
