# J

## 人物概要
1990年代初頭のサンフランシスコ・ハイトストリートを拠点とする自動車整備士であり、昔気質の錬金鍛冶屋。「ハイトストリートの守護者」と呼ばれ、街の住民たちから厚い信頼を寄せられている。愛車のカスタムマシンや隕鉄から鍛えたボウイナイフを愛用し、口はやや荒いが情に厚く強い義侠心を持つ。妹のパウリナを深く気にかけている。

Ver.2.0「疾走れ！ゴールデンシティへ」（および個別エピソード「J・サンフランシスコボーイ」）では、ゴールドラッシュの歴史を引くゴールデンシティ・サンフランシスコを舞台に、マフィアの暗躍や違法神秘術回路を用いた暴走・電磁破壊テロの危機に直面。ヒッピーの少女[[マーキュリア]](マーキュリア.md)や財団調査員の[[マチルダ]](マチルダ.md)、[[パイオニア]](パイオニア.md)らと協力し、卓越した整備・操縦技術を活かしてハイウェイでの危険な高速カーチェイスやアジト急襲を敢行。街と仲間たちを守り抜いた。

メインストーリー[[第13章「他者の哀しみ」]](../story/main/第13章_他者の哀しみ.md)では、聖パブロフ財団本部に滞在していた際にマヌス・ヴェンデッタの強襲とストーム襲来の危機に直面。役に立つかどうかで避難民を選別・排除する財団の冷酷な方針に怒りを覚えながらも、「自分を守れない弱者を守る」という一貫した信念のもと、「カミソリ」や[[ドルーヴィスIII]](ドルーヴィスIII.md)らと連携して生存者（[[イーグル]](イーグル.md)やストレンジャー）の救援や前線での防衛戦に尽力した。
