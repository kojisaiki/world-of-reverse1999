# イーグル（Eagle / シルバーウイングイーグル）

## 基本情報
- **レア度**: ★5
- **本源**: 木
- **ダメージタイプ**: リアル
- **戦闘タグ**: アタッカー モキシー サポート 追撃
- **CV**: 野口瑠璃子
- **実装バージョン**: Ver.3.7（3周年記念アップデート「他者の哀しみ」）
- **属性・展示**: 1910年代に16年間展示（夏、7月21日完成）。米国ワシントンD.C.で展示された後、ラプラス計算科学研究センターに移管。ローレンツ研究所でも活動が確認される。

## 人物概要
聖パブロフ財団第一防衛学校の優等生。初期実装の★4キャラクター「[[リトルイーグル]](リトルイーグル.md)」から3年の歳月を経て成長した姿であり、本作初の「同一キャラクターの別バージョン（成長版SPユニット）」として実装された。展示年数も13年から16年へと3年延びており、背丈も伸びてスカウト技術と弓矢の技量を一段と磨き上げている。ゲーム内でも[[リトルイーグル]](リトルイーグル.md)と絆レベルを共有する。

## 主な登場ストーリー

### メインストーリー
- [[第13章「他者の哀しみ」]](../story/main/第13章_他者の哀しみ.md)
  - 2007年、聖パブロフ財団本部および第一防衛学校が[[アルカナ]](アルカナ.md)率いるマヌス・ヴェンデッタの大規模な急襲とストーム襲来に見舞われた際、学校と仲間たちを守るため奮戦。[[J]](J.md)や[[ドルーヴィスIII]](ドルーヴィスIII.md)らと連携し、避難民（ストレンジャー等）の救援や前線での防衛戦を担った。
  - ※なお、以前の一部記述にあった[[第3章「物語は何処にもあらず」]](../story/main/第3章_物語は何処にもあらず.md)は、ヴェルティ幼少期（2003年）の学校脱走事件を描く過去編であり、本編シナリオ上にイーグルは登場しない（第3章クリア後に成長前であるリトルイーグルの逸話『エグゼビア探し』が開放されるというゲーム進行上の関連がある）。

### サブストーリー / キャラクターエピソード（逸話）
- **キャラクターエピソード（逸話）：『嵐の中、幼き鷹は羽ばたく』（The Eaglet Takes Wing）**
  - Ver.3.7にて実装。幼少期からの歩みや直面した苦難を乗り越え、自らの翼で力強く羽ばたくイーグルの成長を描いた専用エピソード。
