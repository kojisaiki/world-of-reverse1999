# リトルイーグル（Little Eagle）

## 基本情報
- **レア度**: ★4
- **本源**: 木
- **ダメージタイプ**: リアル
- **戦闘タグ**: アタッカー
- **CV**: 野口瑠璃子 / エレノア・ベネット（Eleanor Bennett）
- **実装バージョン**: Ver.1.0
- **属性・展示**: 1910年代に13年間展示（夏、7月21日完成）。米国ワシントンD.C.で展示された後、ローレンツ研究所に収蔵。

## 人物概要
ボーイスカウトの最高位「イーグルスカウト」を目指して日々鍛錬に励む、勤勉かつ不屈の少女。聖パブロフ財団第一防衛学校の生徒であり、ラプラス計算科学研究センターの研修生でもある。出征したまま帰らぬ人となった父の面影を追い、記章（バッジ）を手に自身の道を歩んでいる。

後に3年の時を経て成長した姿が★5キャラクターの「[[イーグル]](イーグル.md)」であり、年齢が上がった同一人物にあたる。

## 主な登場ストーリー

### サブストーリー / キャラクターエピソード（逸話）
- **キャラクターエピソード（逸話）：『エグゼビア探し』（Finding Xavier）**
  - ボーイスカウト入隊を志すリトルイーグルが、行方不明となった「エグゼビア」の捜索任務に挑む中で、化学工場で任務中の[[X]](X.md)と遭遇する物語。この一件を通じてローレンツ研究所とも接点を持つことになる（メインストーリー第3章クリア後に開放）。

※メインストーリー本編（第1章〜第12章）には主要キャラクターとしての直接の登場はないが、後に成長した姿（[[イーグル]](イーグル.md)）として[[第13章「他者の哀しみ」]](../story/main/第13章_他者の哀しみ.md)で防衛戦に参加する。
