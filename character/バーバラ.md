# バーバラ（Barbara）

**Barbaraは[[メェプル]](メェプル.md)の英語版名。** 日本語版と英語版のVer.2.1第14節で、同じUTTU編集者がこの二つの名で登場する。人物情報と登場記録はメェプルのノートに集約する。[日本語台本](https://uttu.merui.net/story/event/2_1/jp/?part=14)・[英語台本](https://uttu.merui.net/story/event/2_1/en/?part=14)

この表記をチューズデーの妹に当たる別人物として扱わない。
