# 第0章「明日へ」（This is Tomorrow / プロローグ）

## 基本情報
- **現象界の年代・場所**: 1999年12月31日（現代・世紀末） → 1966年 イギリス・ロンドン
- **主要登場人物**: [[ヴェルティ]](../../character/ヴェルティ.md)、[[レグルス]](../../character/レグルス.md)、[[APPLe]](../../character/APPLe.md)、[[ソネット]](../../character/ソネット.md)

## 概要・あらすじ
1999年12月31日23時59分、[[1回目のストーム]](../../event/storm/1回目のストーム.md)が発生し、現代文明が消失して時代が過去へ巻き戻る現象が起きる。

ストームの影響を受けない特異体質のタイムキーパー・[[ヴェルティ]](../../character/ヴェルティ.md)は時間を逆行し、1966年のイギリス・ロンドンに到着する。ヴェルティは海上で無認可のロックラジオ局を運営していた海賊船長[[レグルス]](../../character/レグルス.md)および[[APPLe]](../../character/APPLe.md)と接触。ストームの接近に伴い消失の危機に瀕した二人を、自身の特殊なスーツケース内に収容して保護する。その後、聖パブロフ財団の調査員[[ソネット]](../../character/ソネット.md)と合流し、財団本部からの指令のもとで新たな任務へと向かう。
