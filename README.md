# World of Reverse: 1999

スマートフォン・PC向けゲーム『**リバース：1999（Reverse: 1999）**』の設定・事実・年表・ストーリーを整理・記録するためのデジタル保管庫（デジタルガーデン）です。

Obsidian Vault として管理され、GitHub Pages 上で [Quartz v4](https://quartz.jzhao.xyz/) を利用して Web サイトとして公開されています。

🌐 **公開サイト**: [https://kojisaiki.github.io/world-of-reverse1999/](https://kojisaiki.github.io/world-of-reverse1999/)

---

## 🤖 AI駆動による作成・編纂

本リポジトリの各種ドキュメント、年表、考証および構成は、**AIエージェント / LLMを活用した「AI駆動（AI-driven）」** で作成・更新・メンテナンスされています。

ゲーム内の膨大なテキストやストーリー記録から事実・エビデンスを抽出し、客観時間と現象界の二重構造などのタイムラインを体系的に整理しています。
